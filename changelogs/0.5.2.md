# 0.5.2

## TLDR;

- **Redesigned Mod Store** with category filters, improved descriptions and image galleries.
- Added **customizable Discord Rich Presence**.
- **Improved Mod Management** with dependency controls, quick uninstalling and more.
- Resource packs and shaders are now integrated into the Mods screen.
- Added **playtime tracking** and persistent running game detection.
- Major **UX and performance improvements**, alongside numerous bug fixes.

Thank you for your patience! It took 10 months to make this release, compared to our usual 3 month schedule. This was caused by burnout, personal problems, and me being really busy with life.

I don't expect my availability to improve significantly until around April 2027, so future releases may continue to take longer than usual.

---

# Discord Rich Presence

- Added support for displaying your status in Discord through Rich Presence
- Fully customizable: you can display any text or data
  (such as game version or instance name)

---

# Mods

## Mod Store

- Redesigned, now with a new look and many features
- Added category filters:
  - Filter mods, resource packs and shaders by various search categories!
- Mod Descriptions: now with cleaner UI, links and gallery viewer
  - Mods menu: Right click -> **Mod Details** now
    takes you directly to description page

## Recommended Mods

- Improved menu design with two columns, filters and increased information density
- Added more curated mods (thanks [@Void98](https://github.com/void90user/))

## Other

- Resource packs and shaders can now be managed from the
  Mods screen, and are visible in the list
- Improved control over dependencies now with deletion/toggling
  - Also you can now hover over a dependency mod to see what depends on it!
- Added "Copy ID" context menu option in Mods list
- Added a quick-uninstall button to Mod Store
- Added a more visible toggler to mods list for enabling/disabling mods
- Disabled mods now stay disabled when updating

# Features

- Environment variables can now be set in instance settings
  (thanks [@SreehariAnil](https://github.com/SreehariAnil/))
- Automatic changelog generation after updating mods, showing version changes
  (thanks [@Void98](https://github.com/void90user/))
- Added success notification messages for common tasks
  (eg: installing/uninstalling mod loaders, importing/exporting presets)
- New global launcher behavior on game launch:
  - Option to **minimize** (new), close, or do nothing after launching a game
  - Moved from per-instance settings to global launcher settings

# UI/UX

- Changed UI styling to be more skeuomorphic (gradients, gloss, depth).
  - Be sure to share your feedback in our discord!
- Improved design of Launcher Settings, moved many things to new "Launcher" page

# Server Manager

(still experimental, enable with `--enable-server-manager`)

- Now servers and clients are unified in one list
  - List now updates in real time if your instances change on disk

# Technical

## Caching

- Now all network requests undergo HTTP caching.

# Fixes

- Fixed "system theme" error spam on Raspberry Pi OS, LXDE, Openbox, etc
- Fixed launcher auto-updater not supporting `.tar.gz` files (only `.zip`)
- Fixed Java binary not being found on Linux ARM
- Fixed switching to server manager messing up folder organization
- Fixed Logs tab not being updated when switching instances
- Fixed one instance's log output showing up in another
- Fixed up/down arrow key instance selection following creation date order
  rather than the order shown in sidebar
- Fix error spam on LXQt
- Reduced clashing between sidebar resizing and scrollbar in main menu

## Mods

- Fixed major performance issues and memory usage in Mods screen and
  Mod Store when browsing large mod lists
  - Root cause: excessively high-resolution mod icons (up to 1080p/4K)
  - Icons are now downscaled to 40×40
- Fixed NeoForge unable to install on Minecraft 26.1 and above
- Fixed game log having broken newlines
- Fixed fabric installation failure on very old versions (eg. classic)
- Fixed Modrinth pages sometimes appearing after selecting Curseforge,
  and vice versa
- Fixed mods installed through Curseforge modpacks internally being
  stored as Modrinth mods
- Fixed freeze when uninstalling Optifine in an Optifine + Forge setup
- Fixed buggy version handling of 26.x versions
- Fixed crashes in certain 26.2 pre-releases and 26.1 snapshots
  (now bypasses BetterJSONs, uses Mojang manifests)
